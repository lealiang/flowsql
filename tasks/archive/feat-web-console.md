# Feature: Web 控制台

状态：`[x]` 已完成

## 业务意图

提供可操作的任务、通道、算子和系统状态管理界面，支持全屏布局、主题切换和关键状态观测。

## Non-Goals

- 不在前端复制后端业务状态机或执行逻辑。
- 不把 UI 轮询改造成跨进程长连接推送。

## 公共契约

前端通过统一 API 客户端访问 health、channels、operators、tasks 和结果接口；页面状态以服务端响应为准，失败响应展示结构化错误。

## 主链路

1. 控制台加载服务健康、通道和算子目录。
2. 用户提交或查询任务，界面轮询状态并展示结果摘要或失败原因。
