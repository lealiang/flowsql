# Feature: Pipeline 与异步任务

状态：`[x]` 已完成

## 业务意图

支持多算子、多源 Pipeline 和异步任务执行，提供取消、超时、结果摘要及结构化诊断。

## Non-Goals

- 不持久化完整执行结果数据集。
- 不在单条 SQL 内部强制中断驱动操作；取消粒度为语句间。

## 公共契约

任务请求包含 SQL 序列、输入输出通道和可选超时；`TaskSnapshot` 至少包含 `pending/running/completed/failed/cancelled/timeout` 状态、错误和诊断摘要。多输入算子通过统一 Work 调用并兼容单输入算子。

## 主链路

1. 提交请求进入任务队列，按 SQL 顺序构造并运行 Pipeline。
2. 每条语句前检查取消/超时，结束后写入状态、行数、耗时和算子列表。
