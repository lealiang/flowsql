# Feature: C++ 算子插件

状态：`[x]` 已完成

## 业务意图

支持用户独立编译 C++ 算子 `.so`，并在运行时上传、激活、去激活和安全卸载，无需重启服务。

## Non-Goals

- 不允许执行中的插件被强制 `dlclose`。
- 不为 C++ 算子建立独立于 Catalog 的管理 API 和状态源。

## 公共契约

`BinAddonHostPlugin` 管理插件文件和生命周期；操作请求以 `plugin_id` 标识，激活前执行 ABI、符号和名称冲突校验，激活后注册到 `IOperatorRegistry` 并同步 Catalog。

## 主链路

1. 上传插件并完成静态校验，调用激活接口加载并注册算子。
2. 去激活检查 `active_count` 和任务引用，满足条件后卸载并更新目录状态。
